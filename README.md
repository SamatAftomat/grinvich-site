# Гринвич — сайт

Одностраничный сайт для **«Гринвича»** (ООО Гринвич) — торгово-монтажной
фирмы в Тольятти: пластиковые окна, остекление и отделка балконов,
москитные сетки, сервис окон, межкомнатные и входные двери.

- Данные: карточка [2ГИС](https://2gis.ru/togliatti/firm/3096754025219334) —
  4,5 ★, 194 оценки, 193 отзыва, 87 фото, прайс из 465 позиций, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–16
